# MetallurgyPlus

MetallurgyPlus is a Minecraft mod which focuses on more ores, materials and alloys.
This mod is by far not realistic but it is rooted in reality. 
Therefore, recipes and (especially) ore generation have been stylized and "minecraftified"
to preserve the fun. This mod is intended to be added to a modpack where each material or
alloy can have a purpose. Currently this mod has 0 progression or purpose other than adding
the materials.
